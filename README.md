# 🌟 Dinamik CV Web Uygulaması | ASP.NET MVC5 ile Kişisel Portföy Projesi

Bu proje, **ASP.NET MVC 5** ve **Entity Framework Database First** mimarisi kullanılarak geliştirilmiş, yönetilebilir panelli dinamik bir **kişisel CV & portföy web uygulamasıdır**.

Modern tasarımı, yönetilebilir içerik yapısı ve veritabanı entegrasyonu ile, bireysel deneyim ve yetkinliklerin dijital ortamda sergilenmesini amaçlar.

---

## 🎯 Projenin Amacı

Geliştirilen bu uygulama, yazılım geliştiriciler ve dijital portföy oluşturmak isteyen profesyoneller için referans bir projedir.  
Amacım, hem teknik becerilerimi sergilemek hem de gerçek dünya senaryolarına uygun bir web çözümü sunmaktı.

---

## 🚀 Uygulama Özellikleri

### 👨‍💼 Ziyaretçi Paneli
- Kişisel bilgiler, eğitim, deneyim, yetenek ve proje bölümleri
- Ziyaretçilerin mesaj bırakabileceği iletişim formu
- Dinamik içerik gösterimi (veritabanından çekilen veriler)

### 🔐 Yönetici Paneli (Admin)
- Güvenli giriş (Authentication & Authorization)
- Tüm içerikler için CRUD işlemleri
- Sertifika, proje ve yetenek görsellerini yönetme
- Kolay içerik takibi için dashboard sayfası

---

## 🧰 Kullanılan Teknolojiler

| Katman | Teknolojiler |
|--------|--------------|
| Backend | ASP.NET MVC5, Entity Framework (Database First), Microsoft SQL Server |
| Frontend | HTML5, CSS3, Bootstrap 4, JavaScript |
| Diğer | LINQ, Authorization, Session Yönetimi, Partial Views |

---

## 🧠 Proje Sürecinde Edindiğim Deneyimler

Bu projeyi geliştirirken;

- **MVC mimarisinin katmanlı yapısını** etkin şekilde uyguladım
- **Veritabanı ile dinamik yapı kurma** konusunda pratik kazandım
- CRUD işlemleriyle **tam yönetilebilir içerik sistemi** kurdum
- Gerçek dünya projelerine yakınlaştıran **auth yapıları ve yönetici paneli** geliştirdim
